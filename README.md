# 🎧 BLTS Tracker (Bluetooth Headphone Battery Tracker)

Нативное легковесное приложение для macOS, которое отслеживает заряд аккумулятора ваших Bluetooth-наушников в **режиме реального времени** прямо в строке меню (Menu Bar).

---

## ✨ Возможности

- 🔋 **Отображение в Menu Bar в реальном времени**:
  - `🎧 85%` — компактный вывод процента заряда активных наушников.
  - Поддержка TWS-наушников с раздельным зарядом: **Left / Right / Case** (AirPods, FreeBuds, Galaxy Buds и др.).
  - Автоматическое обновление при подключении и отключении наушников.
- 📊 **Интерактивное выпадающее меню**:
  - Графический индикатор заряда (`[████████░░] 80%`).
  - Быстрое подключение / отключение любого сопряженного устройства в 1 клик.
- 🪟 **Красивое окно Dashboard (SwiftUI)**:
  - Круговые анимированные кольца заряда.
  - Детальная информация по каждому устройству.
- ⚠️ **Уведомления о низком заряде**:
  - Предупреждает при падении заряда ниже порога (10%, 15%, 20%, 25%).
- ⚙️ **Гибкие настройки**:
  - Частота опроса (1 сек, 2 сек, 5 сек, 10 сек).
  - Режим отображения: `Иконка + Процент`, `Только Процент`, `Только Иконка`.

## 📂 Структура проекта

- `Sources/blts_tracker/Services/BluetoothTracker.swift` — движок мониторинга Bluetooth (`IOBluetooth` + `IOKit`).
- `Sources/blts_tracker/Services/SettingsService.swift` — менеджер настроек и порогов уведомлений.
- `Sources/blts_tracker/UI/MenuBarController.swift` — управление иконкой и меню в строке состояния macOS.
- `Sources/blts_tracker/UI/DetailWindowView.swift` — SwiftUI панель управления.
- `build_app.sh` — скрипт компиляции и сборки `.app` бандла.
